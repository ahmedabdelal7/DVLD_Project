# DVLD v1.0.0

## Driving & Vehicle License Department

DVLD is a desktop application designed to manage driving license operations and the different services provided by a Driving & Vehicle License Department.

The system manages the complete workflow of applicants, applications, tests, drivers, and driving licenses while applying the required business rules throughout the licensing process.

### 📝 License Issuance & Testing

The system manages the required testing process for obtaining a driving license:

1. Vision Test
2. Theory Test
3. Practical Driving Test

* Schedule test appointments.
* Record test results.
* Track passed and failed tests.
* Support test retakes after failure.
* Ensure tests are completed in the required order before issuing a license.

### 🌍 International Driving Licenses

* Issue international driving licenses for eligible drivers.
* Manage international license applications.
* Apply the required eligibility rules for international licenses.
* Maintain license information and history.

### 🔒 Detained Licenses

* Detain driving licenses.
* Record the detention information.
* Manage detained licenses.
* Release detained licenses after the required conditions are met.

### 👥 User Management

* Add and manage system users.
* Link users to people in the system.
* Edit and delete users.
* Activate or deactivate user accounts.
* Change user passwords.
* Manage user-related information and access.

## Architecture

The application is designed using a **3-Tier Architecture** to separate responsibilities between different parts of the system:

* **Presentation Layer (PL)** — User Interface and application interaction.
* **Business Logic Layer (BLL)** — Business rules and application logic.
* **Data Access Layer (DAL)** — Database operations and data persistence.

## Technology Stack

* C#
* .NET Framework
* Windows Forms
* SQL Server
* ADO.NET
* 3-Tier Architecture
* Visual Studio
